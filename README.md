# Stock Tank

A clean, beginner-friendly stock analysis platform for **Indian equities**, built by FinFuse.

## Features

- Search NSE/BSE stocks by name or ticker
- Key financial ratios with beginner-friendly tooltips (PE, EPS, ROE, Book Value, Debt/Equity)
- 1Y / 3Y / 5Y price charts
- Business summary and holding pattern
- Backend API proxy with 45–60s caching

## Tech Stack

- Next.js (App Router)
- Tailwind CSS
- Chart.js
- Yahoo Finance API (via `yahoo-finance2`)

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Deploy

Deploy to [Vercel](https://vercel.com) with zero config.
